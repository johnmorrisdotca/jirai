## 仕組み

生成は答えの配列を持ち、探索で候補の盤を確認します。状態の操作から、推論や表示のために見える状態を作ります。描画はマスのモデルを作り、標準の表示は操作、コールバック、後始末を扱います。要素と任意の React は、それぞれの表示先を管理します。[元の完全なソース一覧](../architecture.md)は、そのまま残しています。

## ドキュメント

公開する TypeScript の宣言から、各言語のリファレンス、確認した例、ガイドを作ります。Pagefind の検索はブラウザー内で動き、Markdown と llms のファイルも作ります。この追加で、生成、答え、見える数字、表示の役割は変えません。
